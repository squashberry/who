WHO Relay

How to use WHO Relay

Relay lets one WHO Android device share its available internet connection with another WHO device through a paired WHO session.

Before you start

Have two WHO devices nearby

Install the same current WHO beta on both devices. Put the device with working internet access in Share/Host mode and the device that needs the connection in Receive mode.

Important

Turn off normal hotspot when WHO asks

Relay can use its own connection path. If WHO warns that a normal Android hotspot conflicts with Relay, use the Android settings action it provides to turn the hotspot off.

Step 1

Start Share / Host

On the device that has internet, open WHO, open Relay and choose the Share/Host mode. Keep that device connected to its internet source and leave the Relay screen available while pairing.

Step 2

Start Receive

On the second WHO phone, open Relay and choose Receive mode. Use nearby discovery when available, or enter the pairing code shown by the host.

Step 3

Confirm the session

Check that the pairing code matches before accepting. WHO uses a fresh session credential rather than asking you to reuse a permanent password.

Step 4

Connect the receiver

After the session is accepted, start the connection on the receiving device. If Android asks WHO for VPN permission, approve it so the receiver can use WHO's native tunnel path.

Step 5

Check the session state

Watch the Relay screen for connected state and traffic information. If the receiver loses the session, stop and reconnect instead of assuming traffic is still being routed.

Step 6

Stop when you are done

Disconnect the receiver first, then stop the host session. Turn normal hotspot back on only if you intentionally need Android's standard hotspot afterward.

Relay troubleshooting

No discovery

Keep both phones nearby, make sure WHO has the network/nearby permissions it requests, and try entering the session code manually.

Pairing fails

Start a fresh Relay session and use the newly displayed code. Do not reuse an old code.

Android hotspot warning

Disable the normal hotspot using Android settings, then return to WHO and start Relay again.

No traffic

Confirm the host actually has internet, the session says connected, and the receiver's VPN permission was approved.

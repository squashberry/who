WHO for Developers

Developer integrations are planned, but no public WHO API is being offered yet.

Future API

A future developer program may expose carefully scoped identity and reputation capabilities. Access, rate limits and permitted use will be documented before any API is opened publicly.

Security first

Developer access will use scoped keys, authentication, monitoring and abuse controls. Never trust a public API with data or permissions it does not need.
